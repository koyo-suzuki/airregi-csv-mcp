# 要件：エアレジCSV取得MCPサーバー

今のMacアプリ（画面つきの集計アプリ）を、AIから呼べるCSV取得ツールに作り替えます。この文書は、作り始める前に決めた内容をまとめたものです。

## 目的

Claude DesktopやClaude CodeなどのAIから、エアレジの帳票CSVを取得できるようにします。AIは「どの帳票を、どの店舗で、いつからいつまで」を指定するだけで、CSVを手元に保存できます。

## 決めた内容

| 項目 | 内容 |
|---|---|
| 形 | MCPサーバー（stdio接続）と、コマンド（`src/cli.mjs`）。画面は作りません |
| 対応OS | Mac と Windows |
| 動かす場所 | 利用者のパソコンの中だけ |
| AIにさせること | CSVを取得して保存するだけ。集計はしません |
| ログインが切れたとき | 当面は「手動でログインしてください」と返して止めます |

## 対象の帳票

| 帳票 | 状態 |
|---|---|
| バリエーション別売上 | 取得できます（画面で確認済み） |
| 日別売上 | 取得できます（画面で確認済み） |
| 商品別売上 | 取得できます（画面で確認済み） |
| 会計明細 | 取得できます（画面で確認済み） |

帳票ごとの違いは「帳票の定義」として分けて書きます。帳票を足すときは、定義を1つ追加します。

## ツール

| ツール | 入力 | 返すもの |
|---|---|---|
| `list_reports` | なし | 取得できる帳票の一覧 |
| `list_stores` | なし | 店舗の一覧 |
| `start_download` | 帳票、店舗（複数可）、開始日、終了日、保存先（任意） | `job_id` |
| `get_download` | `job_id` | 進み具合、保存したCSVの場所、店舗・期間ごとの成否 |
| `cancel_download` | `job_id` | 中止の受け付け |
| `status` | なし | Chromeを開いているか、実行中の取得の有無、保存先 |
| `open_login` | なし | ChromeでAirレジのログイン画面を開きます |

取得には時間がかかり、AIの側でツールの呼び出しが時間切れになるおそれがあります。そのため、取得は `start_download` で始めて、`get_download` で結果を確かめる形にしました。

## 守ること

今のアプリの方針のうち、次の内容は引き継ぎます。

- 取得に失敗した店舗や期間を「売上ゼロ」として扱いません。成否を店舗・期間ごとに返します。
- 画面の店舗名、期間、ダウンロードしたファイル名が指定と一致するかを確かめます。一致しなければ止めます。
- Airレジ以外の画面へ移動したら止めます。
- ログイン状態のファイルや、取得したCSVは、ユーザーのフォルダの中に保存します。
- ログやAIへの返事に、ログイン情報を出しません。

## 保存先

| OS | 場所 |
|---|---|
| Mac | `~/Library/Application Support/airregi-csv-mcp/` |
| Windows | `%APPDATA%\airregi-csv-mcp\` |

環境変数 `AIRREGI_APP_DATA` で変えられます。

## 今回やらないこと

- 集計（今のRustのエンジンは消します）
- 画面（今のSwiftのアプリとWeb画面は消します）
- 自動でログインし直すこと（あとから足せる作りにします。パスワードの置き場所は、あとで決めます）
- クラウドからの利用

## 確かめ方

- 単体テストは、MacとWindowsのCIで回します。
- エアレジへのログインと実際の取得は、CIでは試せません。利用者のパソコンで確かめます。

## 画面の確認（2026年11月に済み）

4つの帳票すべてを、ログインした画面で確かめ、1店舗・1か月分を実際に取得しました。取得したCSVは、画面の数字と合っていました。

| 帳票 | 画面のURL | 期間の選び方 | 表示の切り替え | ダウンロードボタン | ファイル名の先頭 | 1回で取れる期間 |
|---|---|---|---|---|---|---|
| バリエーション別売上 | `/CLP/view/salesListByMenu/` | カレンダー | 「バリエーション単位で表示」 | 「バリエーション単位の売上(CSV)をダウンロードする」 | `バリエーション別売上_` | 約3年分で出せた（上限は未確認） |
| 商品別売上 | `/CLP/view/salesListByMenu/` | カレンダー | 「商品単位で表示」 | 「商品単位の売上(CSV)をダウンロードする」 | `商品別売上_` | 約3年分で出せた（上限は未確認） |
| 日別売上 | `/CLP/view/salesList/` | 集計対象「日別」と年・月のプルダウン | なし | 「CSVデータをダウンロードする」→「売上集計」 | `売上集計_` | 1か月 |
| 会計明細 | `/CLP/view/salesList/` | 集計対象「日別」と年・月のプルダウン | なし | 「CSVデータをダウンロードする」→「会計明細」 | `会計明細_` | 1か月。前月1日以降の分だけ |

わかったこと：

- 会計明細CSVは、取引履歴の画面ではなく、日別売上の画面から出します。取引履歴の画面のCSVは「入出金履歴」「ジャーナル履歴」です。
- 日別売上の画面で今月を選ぶと、ファイル名の期間は今月の月末までになります（例：`売上集計_20261101-20261130.csv`）。
- 期間の選び方は、帳票の定義の `setPeriod` で帳票ごとに差し替えられます。ないときはカレンダーで選びます。

## 残っている作業

月単位の帳票（日別売上・会計明細）に合わない期間を指定したときは、`start_download` が取得を始める前に `PERIOD_UNSUPPORTED` を返すようにしました（各帳票の `checkPeriod`）。

まだ残っているのは、次の作業です。

- 自動でログインし直すこと（パスワードの置き場所を決めてから）
- 会計明細の「前月1日以降」の制限は画面の説明に従って、ツールの側で止めています。エアレジ側で古い期間を選んだときの動きは試していません。
- カレンダーの帳票で、1回に出せる期間の上限は確かめていません（約3年分は出せました）。今は月ごとに分けて取得しています。
